# About

**Feather Fencer Fechtbuch** is a personal HEMA project maintained by Feather Fencer.

## Publication principles

- Final articles are in English.
- Czech is allowed in clearly marked work-in-progress notes.
- Sources and quotations must be attributed.
- Interpretation, hypotheses, and modern practice must be distinguishable from historical evidence.
- Only material intended for public access belongs in this repository.

## Corrections

Suggest a correction through the linked GitHub repository. Include the page and,
where relevant, the supporting source.
